# ft_select

How to create a simple TUI (Terminal User Interface) in C, using the termcaps library.

## Objective

The main objective is to create a simple program that will take a list of arguments and display them in the terminal, allowing the user to navigate through them using the arrow keys and select them using the space bar. The program should also handle resizing of the terminal window and update the display accordingly. Pressing the ESC key should exit the program cleanly.
